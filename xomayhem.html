XO Mayhem

is a web-based tic-tac-toe game where players compete against an AI in both classic and extended board modes. Designed for quick fun and strategic play, XO Mayhem turns a simple game into a competitive experience.

Client Emily Watson
Sector Education
Duration 1 week

Project Overview

XO Mayhem is a website-based tic-tac-toe game that enhances the classic experience by introducing an extended 5×5 grid and an AI opponent with multiple difficulty levels. The project focuses on combining simple gameplay with strategic depth, allowing players to test their decision-making skills against an intelligent system in a fast and engaging environment.

Our Approach

I redesigned traditional tic-tac-toe by expanding the board size and implementing difficulty-based AI behavior. The system was built to remain easy to use while increasing replayability through smarter AI logic, scalable game rules, and a clean user interface that supports quick interaction and feedback.

How I Did It

Designed Scalable Game Logic

Implemented flexible board handling to support both classic and 5×5 Arena Mode, including dynamic win-condition checking..

Developed Difficulty-Based AI

Created Easy, Medium, and Hard AI levels using progressively advanced decision-making, from random moves to strategic play.

Integrated Interactive Web Interface

Built a responsive and user-friendly interface that connects game logic, AI behavior, and player input for smooth gameplay.
